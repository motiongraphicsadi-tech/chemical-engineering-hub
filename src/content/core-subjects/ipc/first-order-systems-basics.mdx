# Introduction

First Order Systems are the simplest and most common dynamic systems encountered in process control.

Many industrial processes behave approximately as first order systems, including:

- Liquid level systems
- Mixing tanks
- Heat exchangers
- Thermal systems
- Pressure systems

Understanding first order systems is essential because they form the foundation for process dynamics, controller design, and stability analysis.

---

# Why It Matters

Every process takes time to respond to changes.

When a valve is opened, a heater is turned on, or flow rate changes, the process output does not instantly reach its final value.

Instead, the response occurs gradually.

Understanding first order behavior helps engineers:

- Predict process response
- Design controllers
- Tune PID loops
- Improve process performance
- Troubleshoot operating problems

Most industrial control loops can initially be approximated as first order systems.

---

# Core Concept

A first order system contains only one energy storage element.

Examples:

- Liquid stored in a tank
- Heat stored in a thermal system
- Pressure stored in a vessel

Because only one storage element exists, the system is described by a first order differential equation.

The general first order process model is:

$$
\tau \frac{dy(t)}{dt}+y(t)=Kx(t)
$$

Where:

- $y(t)$ = output variable
- $x(t)$ = input variable
- $K$ = process gain
- $\tau $ = time constant

---

# Working Principle

When an input changes:

1. The process detects the disturbance.
2. The output begins changing.
3. The response gradually approaches a final value.
4. Eventually a new steady state is reached.

Unlike ideal systems, real processes require time to respond because of stored energy or material.

The speed of response is determined primarily by the time constant.

---

# Mathematical Definition

The differential equation of a first order system is:

$$
\tau \frac{dy(t)}{dt}+y(t)=Kx(t)
$$

Applying Laplace Transform:

$$
\tau sY(s)+Y(s)=KX(s)
$$

Rearranging:

$$
Y(s)(\tau s+1)=KX(s)
$$

---

# Derivation of First Order Transfer Function

Transfer function is defined as:

$$
G(s)=\frac{Y(s)}{X(s)}
$$

Therefore:

$$
G(s)=\frac{K}{\tau s+1}
$$

This is the standard transfer function of a first order system.

Where:

- $K $= Steady-state gain
- $\tau $ = Time constant

This equation is one of the most important equations in process control.

---

# Change in Output

When a step input is applied, the output changes gradually.

The time-domain response of a first order system is:

$$
y(t)=K\left(1-e^{-t/\tau}\right)
$$

Characteristics:

- Output starts from initial value
- Output increases exponentially
- Output approaches final value asymptotically

The response is smooth and does not oscillate.

---

# Steady State Gain

Steady-state gain indicates how much the output changes for a given change in input.

Mathematically:

$$
K=
\frac{\Delta Output}
{\Delta Input}
$$

A larger gain means a larger output change for the same input change.

Example:

If:

$$
\Delta Input = 2
$$

and

$$
\Delta Output = 10
$$

Then:

$$
K=\frac{10}{2}=5
$$

The process gain is 5.

---

# Time Constant

The time constant is the most important parameter of a first order system.

It determines how quickly the process responds.

Symbol:

$$
\tau
$$

At:

$$
t=\tau
$$

the response reaches approximately:

$$
63.2\%
$$

of its final value.

## First-Order Response Milestones

| Elapsed Time | Approximate Response |
|--------------|---------------------|
| $t=\tau$ | 63.2% of final value |
| $t=2\tau$ | 86.5% of final value |
| $t=3\tau$ | 95.0% of final value |
| $t=4\tau$ | 98.2% of final value |
| $t=5\tau$ | 99.3% of final value (practically steady state) |

After approximately $5\tau $, the system is considered to have reached steady state.

<InfoBox>
A smaller time constant ($\tau$) means a faster system response, while a larger time constant indicates a slower response.
</InfoBox>



---

# Dynamic Response Characteristics

A first order response has the following characteristics:

- Smooth response
- No oscillation
- Single time constant
- Predictable behavior
- Stable response

These characteristics make first order systems relatively easy to analyze and control.

---

# Industrial Applications

First order systems are commonly encountered in:

- Liquid level control
- Tank systems
- Mixing operations
- Heat exchangers
- Thermal systems
- Pressure vessels
- Flow systems

Many real processes can be approximated as first order systems during initial design and controller tuning.

---

# Advantages

Advantages of first order models include:

- Simple mathematical representation
- Easy analysis
- Useful for controller design
- Good approximation for many industrial processes
- Easy interpretation of process behavior

---

# Limitations

Limitations include:

- May not accurately represent complex systems
- Cannot describe oscillatory behavior
- Ignores higher-order effects
- Assumes linear process behavior

More complicated systems often require higher-order models.

---

# Engineering Perspective

Process control engineers frequently perform step tests to determine:

- Process gain
- Time constant
- Transfer function

These parameters are then used for:

- Controller tuning
- Process simulation
- Stability analysis
- Dynamic modeling

Understanding first order behavior is essential before studying higher-order systems and PID control.

---

# Solved Example

A first order process has:

$$
K=4
$$

and

$$
\tau=5 \ minutes
$$

Determine the transfer function.

Solution:

Using:

$$
G(s)=\frac{K}{\tau s+1}
$$

Substituting values:

$$
G(s)=\frac{4}{5s+1}
$$

Therefore:

$$
\boxed{
G(s)=\frac{4}{5s+1}
}
$$

---

# Common Mistakes

Students commonly make the following mistakes:

- Confusing gain and time constant
- Assuming immediate response
- Forgetting steady-state conditions
- Incorrect transfer function derivation
- Misinterpreting time constant

<WarningBox>
A large process gain does not necessarily mean a fast process. Speed of response is determined by the time constant, not the gain.
</WarningBox>

---

# Key Takeaways

- First order systems contain one energy storage element.
- Their transfer function is:

$$
G(s)=\frac{K}{\tau s+1}
$$

- Process gain determines output magnitude.
- Time constant determines response speed.
- At one time constant, the response reaches approximately 63.2% of its final value.
- First order systems are widely used in process control analysis.

# Summary

First Order Systems are the simplest dynamic systems encountered in process control. They are characterized by a single energy storage element, a process gain, and a time constant.

The standard transfer function:

$$
G(s)=\frac{K}{\tau s+1}
$$

is one of the most important equations in control engineering. Understanding gain, time constant, and process response provides the foundation for studying higher-order systems, controller tuning, and advanced process control.
