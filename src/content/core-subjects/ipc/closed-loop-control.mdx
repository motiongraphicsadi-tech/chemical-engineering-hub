# Introduction

Closed loop control is the most widely used control strategy in modern industrial plants.

In a closed loop system, the actual process output is continuously measured and compared with the desired value.

Any difference between the desired value and the actual value is called error.

The controller uses this error to automatically adjust the process and reduce deviations.

Examples include:

- Temperature control
- Pressure control
- Flow control
- Level control

Closed loop control forms the foundation of modern automation.

---

# Why It Matters

Industrial processes are constantly affected by:

- Disturbances
- Load changes
- Feed fluctuations
- Environmental conditions

Without feedback, process variables may drift away from desired values.

Closed loop control helps:

- Maintain product quality
- Improve process stability
- Reduce operator intervention
- Improve safety
- Increase efficiency

Nearly every modern chemical plant relies on closed loop control systems.

---

# Core Concept

The basic concept of closed loop control is feedback.

The controller continuously compares:

$$
Error = Setpoint - Process\ Variable
$$

or

$$
e(t)=SP-PV
$$

Where:

- SP = Setpoint
- PV = Process Variable
- e(t) = Error

The controller uses this error signal to determine the corrective action required.

---

# Working Principle

The operation of a closed loop control system follows these steps:

1. Desired value (SP) is specified.
2. Process variable (PV) is measured.
3. Controller compares SP and PV.
4. Error is calculated.
5. Controller generates output.
6. Final control element adjusts the process.
7. Process variable moves toward the setpoint.

This cycle repeats continuously.

---

# Mathematical Definition

For a feedback system:

$$
e(t)=SP-PV
$$

Controller action depends on this error.

The objective is:

$$
e(t)\rightarrow0
$$

A perfectly controlled process maintains zero error.

In practice, small errors may still exist.

---

# Closed Loop Systems

A closed loop system continuously uses feedback information.

Basic elements include:

- Setpoint
- Controller
- Final Control Element
- Process
- Sensor
- Feedback Path

The measured output is fed back to the controller.

This feedback allows automatic correction of process disturbances.

---

# Feedback Control System

A feedback control system uses process measurements to modify controller action.

General feedback structure:

$$
Output \rightarrow Measurement \rightarrow Controller
$$

The controller continuously receives updated process information.

Advantages of feedback include:

- Automatic correction
- Disturbance rejection
- Improved accuracy
- Better stability

Feedback is the most important feature of a closed loop system.

---

# Open Loop vs Closed Loop

Open loop and closed loop systems differ fundamentally in how control action is generated.

| Feature | Open Loop | Closed Loop |
|----------|----------|----------|
| Feedback | Not Present | Present |
| Error Correction | Not Possible | Automatic |
| Accuracy | Lower | Higher |
| Disturbance Rejection | Poor | Good |
| Complexity | Simple | More Complex |
| Cost | Lower | Higher |

Examples:

Open Loop:

- Timer-based washing machine
- Manual valve operation

Closed Loop:

- Temperature controller
- Flow controller
- Level controller

---

# Transfer Function of Closed Loop Systems

Consider:

$$
G(s)
=
Forward\ Path
$$

and

$$
H(s)
=
Feedback\ Path
$$

The closed loop transfer function becomes:

$$
T(s)
=
\frac{G(s)}
{1+G(s)H(s)}
$$

This is one of the most important equations in control engineering.

It shows how feedback modifies overall system behavior.

---

# Effect of Feedback

Without feedback:

$$
Output=G(s)Input
$$

With feedback:

$$
Output=
\frac{G(s)}
{1+G(s)H(s)}
Input
$$

Feedback generally:

- Improves accuracy
- Reduces sensitivity to disturbances
- Improves stability

Properly designed feedback significantly enhances system performance.

---

# Steady State Gain in Closed Loop

The steady-state gain indicates the final response of a closed loop system.

Using the Final Value Theorem:

$$
K_{ss}
=
\lim_{s\to0}
T(s)
$$

Where:

$$
T(s)
=
\frac{G(s)}
{1+G(s)H(s)}
$$

For unity feedback:

$$
H(s)=1
$$

Therefore:

$$
K_{ss}
=
\frac{G(0)}
{1+G(0)}
$$

Steady-state gain is important for determining final output behavior.

---

# Relationship Between Gain and Error

Higher loop gain generally produces:

- Smaller steady-state error
- Better tracking performance
- Improved accuracy

However:

- Excessive gain may cause oscillations
- Stability can be reduced

A balance must be maintained during controller tuning.

---

# Laplace Transform Application

Closed loop systems are analyzed using Laplace Transform.

The differential equations describing the process are converted into:

$$
Transfer\ Functions
$$

This simplifies:

- Stability analysis
- Controller design
- Dynamic response calculations

Most modern control analysis is performed in the Laplace domain.

Typical objectives include:

Most industrial control loops are implemented as closed loop systems because they provide superior performance compared to open loop control.

# Solved Example

A process has:

$$
G(s)=5
$$

and unity feedback:

$$
H(s)=1
$$

Determine the closed loop gain.

Using:

$$
T(s)
=
\frac{G(s)}
{1+G(s)H(s)}
$$

Substituting:

$$
T(s)
=
\frac{5}
{1+5}
$$

$$
T(s)
=
\frac{5}{6}
$$

Therefore:

$$
T(s)=0.833
$$

The closed loop gain is approximately:

$$
0.833
$$

# Common Mistakes

Students commonly:

- Confuse feedback with feedforward
- Forget the feedback term in the denominator
- Confuse open loop and closed loop systems
- Ignore steady-state error
- Assume higher gain always improves performance

<WarningBox>
Increasing loop gain improves accuracy but excessive gain can cause instability and oscillations.
</WarningBox>

# Summary

Closed loop control systems use feedback to automatically maintain process variables at desired values.

By continuously comparing the process variable with the setpoint, controllers can detect errors and generate corrective actions.

The closed loop transfer function and steady-state gain are fundamental concepts used to analyze, design, and optimize industrial control systems.
