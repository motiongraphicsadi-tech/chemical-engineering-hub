# Introduction

First order systems are among the most common dynamic systems found in industrial processes.

Although the mathematical model appears simple, many real industrial processes exhibit first order behavior.

Common examples include:

- Mercury Thermometer
- Liquid Level System
- Pure Capacitive System

These systems help engineers understand how energy and material storage affect process response.

---

# Why It Matters

Understanding practical examples makes it easier to visualize process dynamics.

Instead of viewing first order systems as mathematical equations, engineers can observe them in real equipment.

Studying these systems helps engineers:

- Understand process response
- Estimate time constants
- Develop transfer functions
- Tune controllers
- Predict process behavior

Many industrial control loops can be approximated using first order models.

---

# Core Concept

All first order systems contain a single storage element.

Examples include:

- Thermal energy storage in a thermometer
- Liquid storage in a tank
- Material storage in a vessel

The general first order transfer function is:

$$
G(s)=\frac{K}{\tau s+1}
$$

Where:

- \(K\) = Process Gain
- \(\tau\) = Time Constant

The response is always gradual rather than instantaneous.

---

# Working Principle

The basic behavior of a first order system follows a common pattern:

1. An input disturbance occurs.
2. Energy or material begins accumulating.
3. Output starts changing gradually.
4. Output approaches a new steady state.
5. Final equilibrium is achieved.

The speed of response depends primarily on the time constant.

---

# Mercury Thermometer

A mercury thermometer is one of the simplest examples of a first order system.

When the surrounding temperature changes:

- Heat transfers to the bulb.
- Mercury expands gradually.
- The reading slowly approaches the actual temperature.

The thermometer cannot respond instantly because thermal energy must be absorbed before expansion occurs.

---

## Dynamic Behavior

If surrounding temperature suddenly increases:

$$
T_{surrounding}
\uparrow
$$

The mercury temperature gradually follows:

$$
T_{mercury}
\uparrow
$$

The response follows an exponential first order curve.

---

## Transfer Function

The thermometer can be represented by:

$$
\frac{T_m(s)}
{T_s(s)}
=
\frac{K}
{\tau s+1}
$$

Where:

- \(T_m\) = Measured temperature
- \(T_s\) = Surrounding temperature

---

# Liquid Level System

A tank with an outlet is one of the most important first order systems in chemical engineering.

Input:

$$
q_{in}
$$

Output:

$$
h
$$

Where:

- $q_{in}$ = Inlet flow rate
- $h$ = Liquid level

---

## Dynamic Behavior

When inlet flow increases:

- Liquid accumulates inside the tank.
- Level gradually rises.
- A new steady-state level is eventually reached.

The tank behaves as a storage element.

---

## Transfer Function

For a linear level system:

$$
\frac{H(s)}
{Q(s)}
=
\frac{K}
{\tau s+1}
$$

Where:

- $ H(s)$ = Level
- $ Q(s)$ = Flow rate

---

<IndustrialInsight>
Many industrial storage tanks are modeled as first order systems during controller tuning and process simulation.
</IndustrialInsight>

# Pure Capacitive System

A pure capacitive system contains storage but no self-regulation.

Examples:

- Tank without outlet
- Material accumulation systems
- Inventory systems

Unlike a normal first order system, the output continues increasing as long as input exists.

---

## Dynamic Behavior

If a constant input is applied:

$$
q_{in}=constant
$$

The stored quantity continues increasing.

There is no natural steady state.

---

## Transfer Function

The transfer function of a pure capacitive process is:

$$
G(s)=\frac{K}{s}
$$

This differs from the standard first order model.

Because no resistance exists, material continuously accumulates.

---

# Comparison of Examples

| System | Storage Element | Output Variable | Typical Response |
|----------|----------|----------|----------|
| Mercury Thermometer | Thermal Energy | Temperature | Exponential |
| Liquid Level Tank | Liquid Volume | Level | Exponential |
| Pure Capacitive System | Material Storage | Inventory | Continuous Increase |

# Mathematical Definition

The general first order differential equation is:

$$
\tau\frac{dy}{dt}+y=Kx
$$

Applying Laplace Transform:

$$
\tau sY(s)+Y(s)=KX(s)
$$

Resulting transfer function:

$$
G(s)=\frac{K}{\tau s+1}
$$

This equation applies to both thermometer and liquid level examples.

---

# Transfer Function Interpretation

The transfer function reveals:

- Process gain
- Response speed
- Dynamic behavior

A larger time constant means:

- Slower response
- Greater lag

A larger gain means:

- Greater output change
- Higher process sensitivity

---

# Dynamic Response Characteristics

All first order examples share common characteristics:

- Smooth response
- Single time constant
- No oscillation
- Exponential behavior
- Predictable dynamics

These properties simplify analysis and controller design.

---

# Industrial Applications

Examples of first order behavior appear in:

- Storage tanks
- Heat exchangers
- Temperature sensors
- Mixing vessels
- Pressure vessels
- Inventory systems

Understanding these examples helps engineers model more complex industrial processes.

# Advantages

Studying practical first order examples helps:

- Visualize process dynamics
- Understand time constants
- Improve controller tuning

---

# Limitations

Limitations include:

- Real systems may not be perfectly first order
- Nonlinear behavior may occur
- Multiple storage elements create higher-order systems
- External disturbances may affect response

Therefore first order models are approximations of reality.

---

# Engineering Perspective

Chemical engineers frequently encounter first order behavior while working with:

- Tanks
- Heat exchangers
- Sensors
- Process vessels

Before designing controllers, engineers often determine:

- Process gain
- Time constant
- Transfer function

These parameters form the foundation of process control design.

---

# Solved Example

A thermometer has:

$$
K=1
$$

and

$$
\tau=20\ seconds
$$

Determine its transfer function.

Solution:

Using:

$$
G(s)=\frac{K}{\tau s+1}
$$

Substituting values:

$$
G(s)=\frac{1}{20s+1}
$$

Therefore:

$$
G(s)=\frac{1}{20s+1}
$$

---

# Common Mistakes

Students frequently:

- Assume immediate response
- Confuse gain and time constant
- Treat pure capacitive systems as self-regulating systems
- Ignore storage effects
- Misinterpret transfer functions

<WarningBox>
A pure capacitive system does not naturally reach steady state because it continuously stores material or energy.
</WarningBox>

# Key Takeaways

- Mercury thermometers exhibit first order thermal response.
- Liquid level tanks often behave as first order systems.
- Pure capacitive systems continuously accumulate material.
- First order systems contain one storage element.
- Time constant determines response speed.
- Process gain determines output magnitude.
